# deviceintelligence-ios

Public Swift Package Manager (SPM) mirror for the **Experian DeviceIntelligence iOS SDK** (Device Intelligence collector for iOS).

This repository holds the consumer-facing `Package.swift` and GitHub Release assets (versioned XCFramework zips) required to integrate DeviceIntelligence via SPM:

```swift
.package(url: "https://github.com/experian-collectors/deviceintelligence-ios", from: "x.y.z")
```

For SDK source, build, and release details, see the internal **DeviceIntelligence iOS** collector project.
